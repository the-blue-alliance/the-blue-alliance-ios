# Installation

fastlane is **not** installed on developer machines and is not needed for local work.
Everything you run day to day is a `make` target at the repo root — run `make help`.

These lanes run only on CI, from [`release.yml`](../.github/workflows/release.yml), which
installs fastlane via Bundler on the runner.

# Available Actions

## iOS

### ios beta_ci

```sh
[bundle exec] fastlane ios beta_ci
```

Upload a new beta build to TestFlight (for CI machine)

### ios app_store

```sh
[bundle exec] fastlane ios app_store
```

Upload a new build to the App Store
